# Browser Companion

1. Open `chrome://extensions` and enable **Developer mode**.
2. Select **Load unpacked** and choose this folder.
3. Use the popup switches to show a cursor-following companion, a bottom-right companion, or both. Your choices are saved across supported tabs.
4. Turn on **Make bottom-right companion clickable**, then click it to fetch a random quote from `https://dummyjson.com/quotes/random`. The quote appears beside the companion and in the page's developer console.

After installing or reloading the extension, reload any already-open pages. Chrome does not allow extensions to run on its internal pages or the Chrome Web Store. To use it on local files, enable **Allow access to file URLs** in the extension's details.
